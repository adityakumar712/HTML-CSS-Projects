## 🚀 How to Use This Repository

Clone the repository:

```bash
git clone https://github.com/adityakumar712/HTML-CSS-Projects.git
```

Navigate into the repository:

```bash
cd HTML-CSS-Projects
```

Then open any project folder and launch its `index.html` file in your browser.

For example:

```text
01-movie-ranking/
        ↓
    index.html
        ↓
     Browser 🌐
```
